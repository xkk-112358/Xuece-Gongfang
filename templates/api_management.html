📡 API 接口说明
方法接口说明
GET /api/question_bank/ 获取该实例的题库数据（题目 + 错题），返回 JSON
POST /api/question_bank/ 上传/同步题库数据，需在 Header 中携带 X-API-Key
请求示例
# GET 请求（无需认证）
curl {{ request.scheme }}://{{ request.get_host }}/api/question_bank/?api_key=YOUR_API_KEY

# POST 请求（需在 Header 中传 API Key）
curl -X POST {{ request.scheme }}://{{ request.get_host }}/api/question_bank/ \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"questions":[],"wrong_questions":[],"last_updated":"2026-06-10"}'
